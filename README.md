# VitalTrack

Aplicativo Android para monitoramento de alimentação, exercícios físicos, peso corporal e evolução da saúde, desenvolvido com Kotlin e Jetpack Compose.

## Principais Recursos

- Registro rápido de refeições
- Controle de calorias e macronutrientes
- Histórico de alimentos consumidos
- Alimentos mais utilizados
- Refeições salvas
- Registro de atividades físicas
- Acompanhamento de peso corporal
- Importação de dados via JSON

## Tecnologias

- Kotlin
- Jetpack Compose
- Material Design 3
- Room Database
- MVVM
- Coroutines
- StateFlow

## Objetivo

Permitir o acompanhamento nutricional e físico de forma simples, rápida e eficiente, reduzindo ao máximo o tempo necessário para registrar refeições e atividades.
